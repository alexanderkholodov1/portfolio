# Portfolio milestones

Priority: galaxy first, portfolio second. No calendar-day allocation. These are this repository's
deliverables, not a combined game/portfolio release train. Galaxy has its own roadmap.

| Milestone | Delivery | Acceptance |
| --- | --- | --- |
| P M0 | Corrected scope, ownership, integration contract and provisional visual direction | Documentation coherent; separate portfolio commit; no game implementation/spec ownership here |
| P M1 | Astro foundation, content schema, language/theme/accessibility base, provisional brand components, public profile/token contract and artifact assembly | Reproducible build, responsive shell, real content only, privacy gate and project deep-link integration checked |
| P M2 | Dedicated portfolio visual/content review | Operator approves identity, composition, navigation and actual content; tentative liquid glass remains adjustable |
| P M3 | Finished profile/project/links pages and independent-project publishing | Real bilingual content, working links, accessible themes, Lighthouse target >=95 on portfolio pages and deployed preview reviewed |
| P M4 | Hosting continuity and operational handover | Existing project pages survive assembly updates; preview/rollback verified; missing artifacts fail clearly |

Game render/design decisions never close a portfolio visual decision automatically. A project
may ship a preview while profile content is incomplete. Final live promotion requires the
relevant integration and content checks. No assistant milestone or dependency is included.

Use versioned branches/PRs for implementation releases; M0 delivers separate documentation commits in each repository, without application implementation. Author commits using the configured operator identity.
