## Portfolio structure (post-fair)
The portfolio is meant to hold many themes; space is only the world where science/BAD lives.
- **"Descent"**: one continuous camera dive on scroll — space (science, BAD) → atmosphere (where
  cosmic rays produce muons; follow one down to the MunHub detector) → Quito in miniature (Pancho Bus
  bus on routes, EfficientTravel, Theatre Quito) → USFQ campus (competitive programming club, IEEE
  Computer Society, tutoring) → underground lab (CASPIAN, Nivela, Trader) → deep ocean (Dragon Ocean
  Analyzer).
- Alternatives: metro map (lines = themes, stations = projects); museum with rooms; floating islands;
  an arcade room with playable games (Sublime Airlift, Minesweeper,
  Nine Men's Morris).
- 3D universe navigable by hand gestures (MediaPipe Hands).
