# Portfolio decisions

## Confirmed by the operator, 2026-10-09

- Portfolio and Galaxy are separate products and repositories. The portfolio will host many
  independent projects; do not place the game's source-of-truth plan in this repository.
- Priority is galaxy first, portfolio second. Complete and commit M0 separately in each repository.
- Build toward a small experience with final-quality standards before expanding breadth.
- The fair QR opens the game directly. Independent portfolio visitors can discover its project
  link, but the portfolio is not an onboarding prerequisite.
- Intention is a game path under `alexanderkholodov.web.app`; the public name/path remain pending.
  `galaxy` is a prototype name and repository identifier, not a final brand commitment.
- Modern liquid glass and the supplied logos are tentative references. Final identity requires
  a dedicated design session. Portfolio identity must support more than the space project.
- Milestones describe outcomes, without calendar-day allocation. The operator owns scheduling.
- The assistant is entirely excluded from current work, including feasibility spikes and scaffolding.

## Retained technical baseline

Astro/static portfolio; English primary and Spanish secondary; light/dark; Firebase Hosting;
versioned external project artifacts assembled only by portfolio for production. Real content
only, no secrets in public output, and verified previews before claiming deployed behavior works.

## Open, not settled by M0

Final typography, layout, glass treatment, public content selection, exact project catalog shape,
game mount path, current cloud access and implementation package versions. The portfolio has
its own design review; tentative visuals are not a closed set of choices.
